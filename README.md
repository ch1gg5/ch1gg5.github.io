## About

This repo hosts my personal site — a landing page for whoever's checking me
out for an internship, placement, or collaboration. First-year CS student
building full-stack systems in Java and Spring Boot, with a growing interest
in ML/AI fundamentals and LLM integration.

Recent work: a full-stack coursework management app (Spring Boot,
PostgreSQL, JWT auth, CI/CD on Render), an A* pathfinder over the
Loughborough campus map, and a couple of Forage job simulations with JPMorgan
and Quantium.

**Stack:** Java · Python · Spring Boot · Spring Security · PostgreSQL ·
JPA/Hibernate · Docker · Apache Kafka · Git

## What's in here

A static site — no build step, no dependencies beyond a couple of Google
Fonts. Structure:

\`\`\`
index.html               Page content
style.css                 Design system
script.js                 Terminal effect + live CV-file check
Daniel_Chigbu_CV.pdf      My CV — powers the View/Download buttons
\`\`\`

The View and Download CV buttons on the site both point at
\`Daniel_Chigbu_CV.pdf\`. Replacing that file (same filename) updates the
live site instantly, no code changes needed. If it's ever missing, the site
detects that automatically and disables the buttons rather than breaking.
